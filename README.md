## Nova Studio

A modern landing page created as a frontend practice project using HTML and CSS. The goal was to improve my understanding of page layout, responsive design, navigation, typography, and UI styling. The project features a full-screen hero section, intuitive navigation, interactive call-to-action button, and social media integration, demonstrating my ability to transform a design concept into a functional web interface.


## Tech stack
- HTML
- CSS
- Unsplash
- Font Awesome Icons


## Features
- Responsive navigation bar
- Modern hero section
- Social media icons
- Clean typography
- Responsive layout
- Hover effects
- Background image with overlay
